# OmniLaya brand

Cream paper, black ink, one watercolor wash. Open [brand-kit.html](brand-kit.html) in a browser for the visual board, or see [brand-kit.png](brand-kit.png).

## The mark

An open ring painted in one brush stroke, with an ink drop inside it. The ring is the whole web ("omni"). The drop is the one point where Laya makes a decision.

| File | Use |
| --- | --- |
| `logo/mark-wash.svg`, `logo/mark-wash-on-night.svg` | Watercolor mark, 48 px and up |
| `logo/mark-flat.svg`, `logo/mark-flat-on-night.svg` | Flat mark for small sizes |
| `logo/favicon.svg` | Browser tab icon on a paper tile |
| `logo/icon.svg`, `logo/icon-maskable.svg` | App icons (the maskable one has room for circular crops) |
| `logo/lockup.svg`, `logo/lockup-on-night.svg` | Mark and wordmark together. The wordmark uses Fraunces; outline the text before print use |
| `logo/*.png` | Raster copies at 512 and 1024 px |
| `logo/wash.svg` | Source of the background wash, shipped as `public/wash.webp` |

Keep clear space of half the mark's width around it. Do not recolor, stretch, rotate, outline or add effects.

Every file is generated by `python brand/make_logo.py` (Python standard library only). Change the geometry or the watercolor filter there, not in the SVG files. The PNG files in `public/` were rasterized from these SVGs with `sharp`.

## Colour

The full system, with reasons, is in [DESIGN.md](../DESIGN.md). In short:

| Name | Hex (night) | Use |
| --- | --- | --- |
| Paper | `#F4EEE3` (`#15140F`) | Page background |
| Sheet | `#FBF8F2` (`#1D1B16`) | Search box, inputs, chips |
| Ink | `#1B1A17` (`#ECE5D6`) | Text, mark, primary button |
| Pencil | `#635F57` (`#A39C8E`) | Secondary text and metadata |
| Rule | `#DDD3C2` (`#34312A`) | Hairlines between rows |
| Fold | `#E7DFCF` (`#221F18`) | Panels under the page, such as the cutting floor |
| Seal | `#B8321C` (`#E4573D`) | Laya's marks only: scores, stamps, underlined choices |
| Link | `#2B3A8C` / visited `#6B2F6B` (`#9BA8F0` / `#C995C9`) | Result links only |
| Error | `#B3261E` (`#F2877E`) | Errors only |

The seal is the one hue. If something red is not a decision Laya made, it is wrong.

## Type

- **Shippori Mincho** (display): the wordmark and headings. 700, with 500 in pencil for "Search".
- **Literata** (print): result titles, snippets and the decision sentence.
- **Hanken Grotesk** (interface): inputs, buttons, chips, metadata.
- **Recursive**, mono and casual axes on (Laya's voice): scores, timings and choices, such as "91 on topic" and "read by laya/english".

The lockup SVGs still set the wordmark in Fraunces; regenerate them with `make_logo.py` after switching its font, and outline the text before print use.

## Texture and motion

- Watercolor lives in the mark and in one wash behind the home search box (9% opacity, 7% inverted at night). Nothing textured sits behind text or inside a control.
- A faint paper grain covers the page at 5% (3.5% at night).
- Motion is feedback only: the enso draws itself while Laya or an engine is working, rows fade in, and each margin mark is written in as its score arrives. `prefers-reduced-motion` turns these off.

## Voice

Short sentences, simple English, no buzzwords, no em dashes. Say what Laya did: "Laya searched Google and Reddit from the past week", "91 on topic", "Show 2 results below the floor".
